## Adding a new idea

Copy an existing page and keep the same sections:

1. **Summary**: one or two sentences.
2. **Goals**: what the mod should achieve for the player.
3. **Inspiration**: other mods or games that do something similar.
4. **Game systems involved**: which XML files, assets or code it touches.
5. **Plan**: phases, smallest useful version first.
6. **Open questions**: decisions still to make.

Then add it to the table above and to the main [README](../../README.md).
